# 🔐 CyberPort - Tu Portfolio de Ciberseguridad en Vercel

Un blog/portfolio moderno y oscuro especializado en ciberseguridad, construido con Vue.js 3, Vite y Tailwind CSS, desplegado en Vercel.

![Vue.js](https://img.shields.io/badge/Vue.js-3-4FC08D?style=flat-square&logo=vue.js)
![Vite](https://img.shields.io/badge/Vite-7-646CFF?style=flat-square&logo=vite)
![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-3-38B2AC?style=flat-square&logo=tailwindcss)

## 🚀 Características

- **Diseño Moderno Oscuro**: Inspirado en portafolios de hacker, con tema cibernético
- **Terminal Interactiva**: Efecto de typing animation en la página principal
- **Blog Dinámico**: Sistema de filtrado por categorías
- **Artículos Completos**: Páginas de detalle con contenido markdown
- **Responsive Design**: Totalmente adaptable a dispositivos móviles
- **Animaciones Suaves**: Efectos hover, glows y transiciones
- **Vercel Ready**: Configuración lista para despliegue automático

## 🛠️ Instalación y Uso

### Requisitos
- Node.js 16+
- npm o yarn

### Pasos

1. **Instalar dependencias**
```bash
npm install
```

2. **Ejecutar en desarrollo**
```bash
npm run dev
```

3. **Compilar para producción**
```bash
npm run build
```

## 📝 Personalización Rápida

- **Cambiar nombre**: Edita `Navigation.vue` y `Footer.vue`
- **Agregar artículos**: Edita `src/data/articles.js`
- **Cambiar colores**: Edita `tailwind.config.js`
- **Redes sociales**: Actualiza URLs en `About.vue` y `Contact.vue`

## 🚀 Despliegue en Vercel

1. Sube tu código a GitHub
2. Ve a [vercel.com](https://vercel.com)
3. Conecta tu repositorio
4. ¡Vercel desplegará automáticamente!
